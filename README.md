# Курс новичка Greenway

Тёплый премиальный сайт-презентация обучающего курса в партнёрстве с Greenway Global, построенный на основе исходной презентации из **14 слайдов**.

**Даты нового потока:** 20–24 октября 2026 года.

**Программа:** точка старта → система вознаграждения → установки и мышление → продукт и продажи → личный бренд.

## Содержание сайта

- Проблемы и вопросы новичка из слайда 2.
- Пять целей обучения из слайда 3.
- Раздел «Они тоже когда-то были новичками» из слайда 4 с предупреждением об индивидуальности результатов.
- Формат уроков из слайда 5.
- Подробное наполнение каждого из пяти уроков из слайдов 6–10, включая практические блоки и образовательные результаты.
- Шесть ожидаемых результатов курса из слайда 11.
- Раздел о переходе от изучения к действиям из слайда 12.
- Призыв присоединиться из слайда 13.
- Условия участия из слайда 14.

В маркетинг-плане указаны **иллюстративные уровни дохода** из оригинального слайда. Они не являются гарантиями или прогнозами доходности. В условиях 50 PV денежный эквивалент ~7 000 ₽ из PDF указан как ориентировочный, поскольку цены могут измениться.

## Открытие сайта

Исходник: `index.html` (HTML + CSS + JavaScript без сборки).

Планируемый публичный адрес GitHub Pages:

https://iliavsevolodov.github.io/greenstart/

В репозитории настроен workflow GitHub Actions для публикации сайта. Если автоматическая публикация не сработает, открой **Settings → Pages**, выбери **GitHub Actions** как источник, затем запусти workflow «Publish Greenway Course» повторно.

## Контакт организатора

Кнопка «Присоединиться» формирует готовый текст для сообщения в Telegram. Сейчас прямой контакт организатора не предоставлен.

Чтобы подключить контакт, открой `index.html` и найди строку:

```javascript
const ORGANIZER_TELEGRAM = "";
```

Вставь `https://t.me/username`. Сайт не хранит данные пользователей и не выдаёт формирование сообщения за поданную заявку.

## Оформление

- Цветовая гамма: тёплый коричневый, бежевый, карамельный, кремовый.
- Типографика: Cormorant Garamond (заголовки) + Manrope (интерфейс).
- Интерактивные аккордеоны уроков, адаптивная верстка, анимации появления и плавная прокрутка.
- Доступность: клавиатурная навигация и поддержка `prefers-reduced-motion`.
- Фотографические фоны загружаются с Unsplash.

Это информационный сайт независимого партнёрского курса, не официальный сайт Greenway Global.
